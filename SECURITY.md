# Security Policy

## Status

RemitX's smart contracts have **not been externally audited**. Do not use them with real funds.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private
[Security Advisories](https://github.com/Northgate-Systems/RemitX/security/advisories/new)
to report it. We aim to acknowledge reports within 72 hours.

## Scope

Soroban contracts in `contracts/`, authentication and API routes in `src/app/api/`, and the Rust crate in `core/`.
